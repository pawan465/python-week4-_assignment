# Employee Salary Project

This project reads employee data, finds the average salary, counts employees in each department, and saves employees above an amount you choose.

## Run the project

1. Open a terminal in this folder.
2. Install Pandas: `python -m pip install pandas`
3. Run: `python employee_analysis.py`
4. Enter a salary amount, for example `60000`.
5. See the results in the terminal and in `employees_above_threshold.csv`.

Keep `employees.csv` beside `employee_analysis.py`. It needs the columns `name`, `department`, and `salary`.
